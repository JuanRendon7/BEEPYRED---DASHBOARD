**CRITICAL:** Instalar `tailwindcss@3.4.19` exacto — NO usar `tailwindcss@latest` (v4 es incompatible con shadcn/ui).

Desde el directorio `client/`:

```bash
cd client && npm install -D tailwindcss@3.4.19 postcss@8.4.47 autoprefixer@10.4.20
```

Crear `client/postcss.config.js` (formato CJS — Tailwind v3 lo requiere):
```js
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

Crear `client/tailwind.config.ts` con tokens completos:
```ts
import type { Config } from 'tailwindcss'

const config: Config = {
  darkMode: 'class',
  content: [
    './index.html',
    './src/**/*.{ts,tsx}',
  ],
  theme: {
    extend: {
      colors: {
        brand: {
          red: '#E31E24',
          'red-hover': '#C41920',
        },
        // Fondo de página y superficies (dark mode)
        page: '#0F1117',
        surface: '#1A1D27',
        'surface-2': '#21253A',
        border: '#2E3250',
        // Texto
        text: {
          primary: '#F1F5F9',
          secondary: '#94A3B8',
          muted: '#64748B',
        },
        // Estados semánticos
        success: '#22C55E',
        warning: '#F59E0B',
        danger: '#EF4444',
        info: '#3B82F6',
      },
    },
  },
  plugins: [],
}

export default config
```

Actualizar `client/src/index.css` (reemplazar contenido completo):
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer base {
  * {
    box-sizing: border-box;
  }
  body {
    @apply bg-page text-text-primary;
    font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
    -webkit-font-smoothing: antialiased;
  }
}
```

Actualizar `client/index.html` — agregar `class="dark"` al elemento `<html>`:
```html
<html lang="es" class="dark">
```

**IMPORTANTE:** shadcn/ui usa `npx shadcn@latest init` pero necesita que Tailwind ya esté configurado. No usar `shadcn-ui` (paquete antiguo) — usar `shadcn`.

Desde el directorio `client/`:

```bash
cd client && npx shadcn@latest init --yes --base-color slate --css-variables
```

Si el comando interactivo no puede completarse con `--yes`, usar los valores:
- Style: Default
- Base color: Slate
- CSS variables: Yes

El comando crea:
- `client/components.json` — configuración shadcn
- `client/src/lib/utils.ts` — función `cn()` con clsx + tailwind-merge

**VERIFICAR** que `components.json` tenga la ruta correcta:
```json
{
  "style": "default",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.ts",
    "css": "src/index.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}
```

**NOTA:** shadcn/ui init puede modificar `tailwind.config.ts` para agregar CSS variables (--background, --foreground, etc.) y agregar CSS custom properties en `index.css`. Esto es ESPERADO y DESEABLE. Los tokens de color que definimos en Task 1 se mantienen en `theme.extend.colors` — shadcn agrega sus propias variables en la capa base.

Instalar componentes base necesarios:
```bash
cd client && npx shadcn@latest add button badge
```

Instalar dependencias que shadcn requiere si no están instaladas automáticamente:
```bash
cd client && npm install clsx@2.1.1 tailwind-merge@2.5.4 class-variance-authority@0.7.1
```
